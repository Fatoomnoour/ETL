# ETL Project (SSIS)

## 📌 Overview

This project is an ETL (Extract, Transform, Load) process built using SQL Server Integration Services (SSIS).

## ⚙️ Tools Used

* Visual Studio (SSIS)
* SQL Server

## 🔄 Process

* Extract data from source
* Transform data (cleaning & formatting)
* Load data into destination database

## 📂 Project Structure

* ETL/ → SSIS packages
* ETL.sln → Solution file

## 🚀 How to Run

1. Open the project in Visual Studio
2. Configure database connection
3. Run the SSIS package

## ⚠️ Notes

* Make sure to update connection strings before running
* No sensitive data is included
